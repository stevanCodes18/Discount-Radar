# Dicount Radar 
**Plataforma inteligente de monitorizacion de precios**

Bienvenidos a la documentacion de **Discount Radar**,una plataforma que permite controlar la evolución de los precios, comparar productos y recibir alertas cuando aparece una oportunidad de compra. 



## Documentacion
 
### Caracteristicas
 
- Principales funcionalidades de Discount Radar.

-  Monitorización automática.

- Historial de precios.

- Comparación entre tiendas.

- Aplicación móvil.

### Alertas de precio

- Creación de alertas.

- Configuración de precios objetivo.

- Recepción de notificaciones.

- Gestión de alertas.

### Como funciona

- Añadir un producto.

- Configurar el seguimiento.

- Consultar la evolución del precio.

- Detectar oportunidades de compra.

### Preguntas frecuentes

- Dudas habituales sobre la plataforma.

- Funcionamiento de las alertas.
 
- Uso desde dispositivos móviles.

- Monitorización de productos
