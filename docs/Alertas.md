# Alertas de precio

**¿Que son las alertas?**
Las alertas permiten indicar a Discount Radar cuando queremos recibir una notificacion sobre un producto.
En lugar de revisar constantemente el precio,el usuario establece una condicion y espera que se cumpla.

## Alerta de precio objetivo
La opcion mas sencilla consiste en inidcar un precio máximo
por ejemplo:
> Quiero recibir una notificacion cuando los auriculares bajen de 90€
Si el producto tiene un precio de 110€, la alerta permanecera activa
cuando el sistema detecte qu ele precio ha bajado a 89€,la condicion se habrá cumplido

### Notificaciones
Las alertas pueden aparecer como notificaciones en el dispositivo del usuario.
El objetivo es que el usuario reciba la información **en el momento en el que se produce una oportunidad**.
por ejemplo:
>¡Precio reducido!
>El producto que estas siguiendo ha bajado a 529€
>tu precio objetivo era 550€

#### Gestionar alertas
El usuario puede consultar sus alertas y modificar su configuración cuando lo necesite.
También puede dejar de seguir un producto o desactivar temporalmente una alerta.

**Ventajas**
* No es necesario comprobar los precios constantemente
* El usuario establece sus propias condicionales
* Las notificaciones permiten reaccionar 
* El historial ayuda a comprobar si la oferta es realmente interesante

*La desicion final de compra siempre corresponde al usuario*
