# ¿Que es Discount Radar?
Discount Radar es una plataforma diseñada para monitorizar los precios de productos en diferentes tiendas y avisar al usuario cuando aparece una buena oportunidad de compra.

¿Quieres comprar unos auriculares pero actualmente cuestan demasiado?¿Estas esperando a que una consola,portatil o un telefono baje de precio?

Con Discount Radar puedes añadir el producto a tu lista de seguimiento,establecer un precio objetivo y dejar que la plataforma se encargue de comprobar su evolucion

¿Que problema soluciona Discouunt Radar?
Comprabar manualmente los precios de un producto en diferentes tiendas puede resultar lento y complicado.Ademas,los precios pueden cambiar en cualquier momento.
Discount Radar automatiza este proceso para que el usuario pueda dedicar su tiempo a otras tareas.

La plataforma permite:

* Monitorizar productos automaticamente.

* Consultar la evolucion historica de los   precios

* Comparar precios entre diferentes tiendas 

* Establecer precios objetivo.

* Recibir notificaciones cuando se detecta una 
oportunidad.

* Gestionar productos desde ordenaor y telefono movil

## Pensado para todo tipo de compradores
Discount Radar puede utilizarse tanto por usuarios particulares como por profesionales que necesitan controlar los precios del mercado.

Un comprador puede utilizarlo para encontrar el mejor momento para comprar un producto,mientras qu euna empresa puede utilizarlo para controlar los precios de sus competidores.
