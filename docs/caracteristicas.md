# Caracteristicas de Discount Radar

**Monitorizacion automatica**

Discount Radar permite realizar un seguimiento de los productos seleccionados sin que el usuario tenga que comprobar continuamente las diferentes tiendas.El sistema consulta periódicamente la información disponible y registra los cambios detectados De esta forma, el usuario puede conocer cuándo ha cambiado el precio de un producto.

## Historial de precios
Una de las características principales es el historial de precios.Discount Radar guarda las variaciones que se producen a lo largo del tiempo para que el usuario pueda consultar cómo ha evolucionado un producto.
Por ejemplo, un producto podría haber tenido la siguiente evolución:

* Enero: 250€
* Febrero:230€
* Marzo:215€
* Abril:189€

Gracias a esta información, el usuario puede determinar si el precio actual es realmente interesante.


### Comparación entre tiendas

La plataforma permite consultar los precios disponibles en diferentes establecimientos,Esto facilita encontrar rápidamente qué tienda ofrece actualmente el precio más bajo.El usuario no necesita abrir varias páginas web y realizar la comparación manualmente.

#### Lista de seguimiento

Cada usuario puede disponer de una lista personalizada con los productos que desea controlar.

Desde esta lista puede consultar rápidamente:

* Nombre del producto
* Precio actual
* Precio anterior
* Variacion de precio
* Tienda donde se encuentra
* Estado de alerta


##### Aplicacion movil

Discount Radar también está pensado para utilizarse desde dispositivos móviles,La aplicación permitira consultar los productos seguidos y recibir notificaciones


##### Privacidad y seguridad

La información asociada a cada usuario se mantiene protegida y el acceso a la plataforma requiere autenticación.Discount Radar está diseñado para que cada usuario pueda gestionar sus propios productos, listas de seguimiento y alertas.
